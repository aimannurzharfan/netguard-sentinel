# Notice

NetGuard Sentinel was built for the Microsoft Agents League hackathon (AI Skills Fest 2026) as a demonstration and educational project.

It is provided as-is, with no warranty of any kind, under the MIT License (see [LICENSE](LICENSE)). It is not intended for production security operations.

This is a security scanning tool. Run it only against systems you own or are explicitly authorized to test. Unauthorized scanning of systems you do not control may be illegal in your jurisdiction.

By default the scanner accepts only localhost and private (RFC1918) targets. Scanning public targets requires setting the explicit `ALLOW_PUBLIC_TARGETS` flag, and doing so is entirely the user's responsibility.
